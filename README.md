# 🎯 Guess My Number

A simple number-guessing game built with vanilla JavaScript. Guess the secret number between **1 and 20** before your score runs out.

## 🎮 How to Play

1. Enter a number between 1 and 20 and click **Check!**
2. The game tells you if your guess is **too high** 🔺 or **too low** 🔻
3. Every wrong guess costs you 1 point (you start with 20)
4. Guess correctly and the screen turns green 🎉
5. Click **Again!** to play a new round — your **highscore** is kept

---

## ✨ Features

- Random secret number generated every round
- Score and highscore tracking
- Input validation for empty guesses
- Game over when the score reaches 0 (the Check button is disabled)
- Visual feedback: background colour and number box change on a win
- Reset the game without reloading the page

---

## 🛠️ Tech Stack

- **HTML5** — structure
- **CSS3** — styling
- **JavaScript (ES6)** — game logic and DOM manipulation

## 🚀 Getting Started

No installation needed.

```bash
git clone https://github.com/prasad-k-s/Guess-My-Number.git
cd Guess-My-Number
```

Then open `index.html` in your browser.
